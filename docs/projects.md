# Active Projects

-   __[AmSC: American Science Cloud](./projects/amsc.md)__

    ---

    The American Science Cloud (AmSC) is a cross-agency, multi-lab initiative to create a user-friendly, cloud-based infrastructure that will enable the Nation's scientists to access, share, and analyze scientific data and tools securely and efficiently.

    [Website](https://amsc.energy.gov)

-   __[HEP-CCE: High-Energy Physics Center for Computational Excellence](./projects/hep-cce.md)__

    ---

    HEP-CCE supports scientific discovery in HEP by providing a center for developing and deploying novel computational techniques and for nurturing the next generation of high-performance computing (HPC)-savvy HEP scientists.

    [Website](https://www.anl.gov/hep-cce)

-   __[LUCID: Low-Dose Understanding, Cellular Insights, and Molecular Discoveries](./projects/lucid.md)__

    ---

    This project aims to use AI to analyze low-dose X-ray images of cells to extract morphological features and other relevant information.

    [GitHub](https://github.com/BNL-LUCID)
